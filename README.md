# Portfolio Performance — SPY Price Data

Fetches the last **2 years of daily closing prices** for **SPY** (SPDR S&P 500 ETF Trust) from Yahoo Finance via `yfinance`, performs data-quality checks, and saves a clean CSV.

## Repo structure

```
portfolio_performance/
├── data/
│   ├── spy_closing_prices.csv   # clean output (generated by script)
│   └── data_quality_report.txt  # quality findings (generated by script)
├── src/
│   └── fetch_spy_data.py        # main script
├── requirements.txt
└── README.md
```

## Setup

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Run

```bash
python src/fetch_spy_data.py
```

Produces `data/spy_closing_prices.csv` and `data/data_quality_report.txt`.

## Data source

| Field | Value |
|---|---|
| Ticker | `SPY` (SPDR S&P 500 ETF Trust) |
| Source | Yahoo Finance via [`yfinance`](https://github.com/ranaroussi/yfinance) |
| Frequency | Daily |
| Price field | **Adjusted Close** (`auto_adjust=True` — splits & dividends applied) |
| Window | `today − 730 days` → `today` |

`auto_adjust=True` was chosen so that the closing price series reflects total-return economics (no artificial price gaps from splits or dividend ex-dates).

## Data quality checks performed

| # | Check | Finding | Action taken |
|---|---|---|---|
| 1 | **MultiIndex columns** (yfinance ≥ 0.2.38 returns `(field, ticker)` tuples) | Present when downloading a single ticker | Flattened to simple column names |
| 2 | **Missing business days** | Gaps align with NYSE holiday calendar (~9–10 per year) | No action needed — Yahoo Finance correctly omits non-trading days |
| 3 | **Duplicate dates** | None expected for SPY; check guards against API quirks | Keep last occurrence if found |
| 4 | **NaN / null prices** | Rare; can arise from API timeouts or partial sessions | Forward-fill from previous trading day |
| 5 | **Prices below $1** | Would indicate corrupt data for an index ETF priced ~$400–600 | Replace with NaN, then forward-fill |
| 6 | **Single-day moves > ±15 %** | Tail events (e.g. COVID crash Mar 2020) can exceed this threshold | Logged but **not removed** — extreme moves can be real |

See `data/data_quality_report.txt` for the run-specific findings.
